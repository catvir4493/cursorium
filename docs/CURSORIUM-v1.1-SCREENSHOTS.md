# CURSORIUM v1.1 运行截图

以下全部是运行中的 WPF 原生窗口截图；并非设计图或静态 UI 原型。主页面与对照图均为 **1280×830 native pixels / 96 DPI**。
窗口背景使用低对比网格，光效来自真实鼠标移动；截图无全局 Apply 操作，使用隔离的 Daily Focus 测试 Profile。
