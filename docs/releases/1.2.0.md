# CURSORIUM v1.2.0 — Cute Collection & Theme Library Expansion

五套实际下载并校验的 Public Domain 指针：Kawaii Cat、Kawaii Pink Heart、Bunny Cute Kawaii、Pastel、Cool Cat。
75 个原始 CUR/ANI，每个文件与原 ZIP 都有 SHA256、作者、来源和授权记录。
Bunny / Pastel 各缺少三种标准角色，明确继承 FROST；其余三套完整。额外角色与备用文件保留。

- 沿用 v1.1 深色三栏、WindowChrome、ThemeCard 与 DesignTokens。
- All / Built-in / Cute / Imported / Favorites；收藏持久保存，不复制主题。
- 原生资源缩略图、作者、动画/完整度、来源与回退详情；Selected 与 Applied 分开。
- ZIP / 目录受控导入，逐角色映射 review，明确选择 fallback；旧单角色导入保留。
- 原始 ANI 顺序与 timing 的动画缩略预览；隐藏/滚出视口停止，释放旧帧和 native handles。
- Apply/Cancel、Profile、主题事务及四种桌面拖尾/独立点击引擎保持原语义。

Release build 零警告/错误。原生资源各 388；核心 178（原 66 全保留）；桌面 85；原 UI 98；集合专项 28 全通过。
桌面脚本没有删改：当前实机仅枚举单个 2560×1440 / 96-DPI 屏，历史双屏四项本轮不可执行。
125%/150% 为逻辑布局模拟。Windows 10、混合 DPI、当前双屏、真实卸载/全新安装未验证。
五个受保护用户文件 SHA256 不变；安装先隔离验证，再完整备份升级真实安装，原数据、原生指针和快捷方式保持。
