# CURSORIUM v1.0.0 — Cursor & Motion Studio

CURSORIUM 把 FROST 原生 Windows 指针与彗尾工具扩展为本地鼠标主题管理软件：两套完整指针、四种运动效果、独立点击反馈和自由组合 Profile。

- FROST / WHITE COMET、Obsidian：15 个原生角色、四种 CUR 分辨率、两个动画 ANI。
- Comet、Minimal、Neon、Stardust 共用一个桌面渲染引擎。
- Off / Soft Halo / Ring 点击效果，保留左右键身份与输入穿透。
- 三栏 WPF UI、本地实时预览、Apply/Cancel、Profile 创建/保存/改名/切换/删除。
- 验证 `.cur` / `.ani` 的角色导入，原始系统配置备份、失败回滚、中断恢复。
- 托盘启用/暂停、可选登录启动、最后成功应用配置的持久化。

## 下载

- `CURSORIUM-Setup-1.0.0-Release.exe`：当前用户安装器，支持升级已安装 FROST。
- `CURSORIUM-1.0.0-win-x64.zip`：自包含 Windows x64 便携版；解压后运行 `FrostWhiteComet.exe`。
- `CURSORIUM-Themes-1.0.0.zip`：两套主题、矢量与预览、JSON 清单。
- `CURSORIUM-Source-1.0.0.zip`：工程源码和文档。
- `CURSORIUM-SHA256SUMS.txt`：四个下载文件的 SHA256。

可执行文件和安装目录沿用 FROST 名称，以兼容原入口、启动项及备份；窗口与开始菜单名称为 CURSORIUM。安装不会自动切换系统指针。关闭面板保留托盘，Quit 停止特效但保留已安装指针。

Windows 10、混合 DPI/多屏、热插拔、睡眠恢复、安全/保护桌面、独占全屏、全新安装/卸载/升级回退往返及长时间资源行为未全部实测。60/120/30 FPS 是调度目标；测量的 WPF 绘制请求数不代表 GPU 展示 FPS。详细证据与局限见仓库 `VALIDATION.md`、`docs/CURSORIUM-DELIVERY.md`。
