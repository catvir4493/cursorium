# CURSORIUM v1.5.2 Preview — Performance Verification & Release Hardening

Preview verification release. v1.4.0 remains Latest Stable; published versions and library assets are preserved.

- Repeated alternating performance observations load frozen production assemblies on exact .NET 8.0.24 / 10.0.13 runtimes, with a fixed separate input driver and observer/timer calibration.
- Explicit warmup/stable records, input-delivery checks, contamination exclusion, resumable evidence and missing-round repair plans improve reproducibility.
- Startup probes, managed state-constructor completion, tray registration and first-window markers have separate meanings. EventPipe wall-time profiles remain separate from CPU measurements.
- Diagnostic no-paint/no-render controls are available for future attribution; these new controls have not been exercised under the user's input-test pause. Production cursor/trail algorithms and visual settings are preserved.
- The retained verifier can run self-contained on 10.0.13 with the exact deployed Core bytes. Stability diagnostics seed a real signed cache fixture.
- Release preparation includes tracked sources only and verifies executable commit, runtime, distribution bytes, source contents and all asset hashes before publication. Negative fixtures validate rejection and byte restoration.

See the [Chinese delivery report](https://github.com/catvir4493/cursorium/blob/cursorium-v1.5.2/docs/CURSORIUM-v1.5.2-DELIVERY.md), [measurement protocol](https://github.com/catvir4493/cursorium/blob/cursorium-v1.5.2/docs/CURSORIUM-v1.5.2-PROTOCOL.md) and [reproduction commands](https://github.com/catvir4493/cursorium/blob/cursorium-v1.5.2/docs/CURSORIUM-v1.5.2-DIAGNOSTICS.md) for actual results and unresolved gates.

The user paused automatic input testing. The matrix contains 153 completed raw trials, 118 accepted after input-condition exclusions, with 21 mode/version groups still short of three rounds. Full WPF/native regressions, active-performance attribution, complete natural-input comparisons, Windows 10/multiple-display/physical mixed-DPI coverage and 24/72-hour stability remain pending release gates. This preview does not claim Steam Ready or a general engine CPU reduction. The current production installation remains v1.5.1.
