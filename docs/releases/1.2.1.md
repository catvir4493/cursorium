# CURSORIUM v1.2.1 — ZIP Directory Safety Patch

保留 v1.2.0 的全部 Cute Collection 资源和功能，补充压缩包导入的中央目录边界验证。

.NET 8 的 [ZipArchive 实现](https://github.com/dotnet/runtime/blob/v8.0.0/src/libraries/System.IO.Compression/src/System/IO/Compression/ZipArchive.cs#L502)
会先读取目录对象，再核对实际 entry 数。单独限制 EOCD 声明的数量不足以约束伪造低计数的归档。
现在先按受控目录边界逐项扫描，核对实际数量、offset/size、字符串长度，然后才构建 ZipArchive。

- 4096 个 entry、EOCD 伪称只有一个的包安全拒绝；线程分配低于 512 KiB。
- 核心与 Windows 原生回合 180 项通过（178 项全部保留，新增两项）。
- 五个原始作者 ZIP / 75 个真实 CUR+ANI 再验证通过，字节与 SHA256 不变。
- Release 构建零警告/错误。无 UI、ThemeService、StudioService、Profile 或拖尾引擎修改。
- 沿用 v1.2.0 的真实桌面 85 / 界面 98 / 集合 28 基线；当前双屏、物理高 DPI、Win10 及卸载限制不变。
- 安装仍先隔离验证、备份再升级，用户数据与原生指针保持。

v1.2.0 tag、Release 和下载文件不改动；这是新的追加补丁。
安装器、便携版、主题包、源码包与 SHA256SUMS 同时提供。
