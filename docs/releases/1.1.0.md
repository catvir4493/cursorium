# CURSORIUM v1.1.0 — Interface Foundation & UX Refinement

v1.1 保留 v1.0 的指针管理、四种拖尾、点击反馈和 Profile，重构真实 WPF 界面与交互。

- 统一深蓝色设计 Token、自定义控件与键盘焦点状态。
- WindowChrome 深色标题栏，原生拖动/缩放/最小化/最大化/还原；支持系统标题栏回退，关闭仍驻留托盘。
- 真实 Live Preview、15 个角色、小工具栏图标、紧跟预览的可换行主题卡片。
- Trail / Cursor / Click 设置分组、Advanced settings、颜色选择和组合/Profile 摘要。
- Apply/Cancel 固定可达；无变化禁用，非法颜色仍可取消；已应用、草稿与保存 Profile 独立。
- 系统恢复位于 Cursor 分组并保留确认。140/180 ms 微交互尊重 Windows 动画设置，可禁用。
- 小窗口图标导航、独立滚动配置、长名称省略及完整工具提示。

## 下载

- `CURSORIUM-Setup-1.1.0-Release.exe`：当前用户安装器，升级现有 CURSORIUM/FROST 安装。
- `CURSORIUM-1.1.0-win-x64.zip`：自包含 Windows x64 便携版，解压运行 `FrostWhiteComet.exe`。
- `CURSORIUM-Themes-1.1.0.zip`：保留的 FROST、Obsidian 与 JSON 清单。
- `CURSORIUM-Source-1.1.0.zip`：源码、文档、实际窗口截图与脱敏验证结果。
- `CURSORIUM-SHA256SUMS.txt`：四个下载文件校验。

固定 executable/安装目录名称保持兼容，UI 为 CURSORIUM。关闭窗口驻留托盘；Quit 结束特效，已安装系统指针保留。
用户配置、Profile、导入主题与原备份沿用原位置，不做数据迁移；独立新增 interface.json 保存 UI 偏好。

66 项核心、89 项桌面、98 项界面检查通过，两套资源各 388 项通过。

九组分辨率/缩放等效工作区与五页可达性通过，但不代表实际 125%/150% 或混合 DPI。
