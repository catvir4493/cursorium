# CURSORIUM v1.5.0 — Stability, Performance & Compatibility (Preview)

这是验证预发布，**不是 Stable / Steam Ready**。v1.4.0 Stable 和历史资源 Release 保持不变。

- 迁移 .NET 10 LTS；自包含 x64 运行时 10.0.13，保留原 exe、命名空间、IPC 和用户数据路径。
- 静止采样降频并保持 Raw Input 响应；即时关闭、会话重检、Overlay/Raw Input 资源释放和绘制/参数复制分配优化。
- 登录托盘延后窗口创建；首次未打开界面的短测内存 176.6 -> 141.7 MiB、GDI 227 -> 28，真实 IPC/缓存/无窗口退出 11/12/5 项通过。滚动显式更新 ANI 可见性。
- 增强原生事务：真实进程中断恢复、外部修改保护、不可变 CUR 完整性、缺失/拒绝访问时安全失败、陈旧配置写入保护。
- 修复 .NET 10 ZIP 目录项兼容；增加重命名中断恢复、重解析点删除防护、自卸载验证和发行文件清单。
- 新增可配置短测及 24/72 小时诊断入口，CSV/JSON、资源/CPU 绘制统计和日志脱敏；没有默认遥测。

构建零错误/警告（WPF manifest 的两宿主 WFO0003 明确例外）。实际通过：核心 180、新恢复 44、桌面 85、界面 98、缓存重启 99、Cute 28、在线安全 51、策展更新 104、网络/WPF 103、FROST/Obsidian 各 388、安装生命周期 16。实际短测 180.57 秒 / 156 轮；隔离跨卷升级通过。用户永久数据及原生配置与最初备份一致。

静止采样 63.90 -> 10.48/s；两万次参数复制约 22.56 -> 2.56 MB 分配。正常托盘各 15 秒观察单核 CPU 1.128% -> 0.720%，GDI/USER 一致。但部分主动模式的 4 秒驱动式 CPU 数值升高，需要专用机低干扰长测复核；不宣称整体性能全面提升。

Windows 10、真实双屏/混合 DPI、热插拔/锁屏/睡眠/RDP/Explorer 重启、独占游戏、24/72 小时、完整历史升级/断电矩阵未全部实测。旧版 journal 无 Intended 字段，仍保留原兼容恢复协议。资源文件在应用外被删除/拒绝访问时需要人工恢复来源。商业代码签名和 Steam 接入留待后续发行阶段。

完整中文报告、原始脱敏数值、矩阵和操作说明见源码的 `docs/CURSORIUM-v1.5-DELIVERY.md`、`docs/CURSORIUM-v1.5-COMPATIBILITY.md`、`docs/CURSORIUM-v1.5-DIAGNOSTICS.md`、`docs/validation/v1.5/`。安装器、便携版、原内置主题包、源码及 SHA256 随本 Release 提供；29 项官方在线内容不变，按需下载。
