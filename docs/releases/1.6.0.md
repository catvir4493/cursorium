# CURSORIUM v1.6.0 Preview — Commercial Foundation & Library Architecture

Community foundation preview. Not Steam Ready. v1.4.0 remains Latest Stable;
the existing D:\CURSORIUM v1.5.1 production installation is unchanged.

- Build-time Development / Community / Steam identities, isolated data roots,
  explicit update ownership and channel-bound distribution manifests.
- Steam output remains a local experimental payload: no AppID, SDK, SteamPipe,
  Cloud integration or enabled native cursor writes. No Steam payload is attached.
- Independently RSA-PSS-signed Library v2 rights metadata binds the unchanged
  v1 catalog and all 29 package identities. Fourteen original MIT online presets
  are content-approved; fifteen third-party cursor packages remain Needs Review.
- Controlled isolated migration, rollback evidence and portable Profile/favorite
  DTOs preserve legacy data and reject private paths/native backups as cloud data.
- Accurate runtime/apphost supplier LICENSE/NOTICE files are now included.
  Existing project MIT licensing and published history are preserved.

Automatic input testing remains paused. Full WPF/native regressions, performance
attribution, Windows 10/physical multi-display/DPI and 24/72h gates remain Pending.
This release does not claim lower engine CPU or finished Steam compatibility.
