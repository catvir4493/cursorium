# CURSORIUM v1.4.0 — Online Library Expansion & Curation

- 29 real online resources: 15 cursor themes and 14 trusted motion presets. Nineteen additions passed the review pipeline; uncertain rights, bad hotspots and weak contrast were withheld instead of inflating the target to 30.
- Six independently signed collections, local metadata/collection search, Animated/Installed/Not Installed filters and compact collection controls.
- Immutable update protection, explicit installed-version preview, pinned applied/Profile versions and correct same-ID Apply/Cancel behavior. Download and favorites never apply Windows pointers.
- Reusable review, native audit, package, production-cover, sign, preflight, public-download and metadata-only publishing tools. Existing catalog v1 remains compatible with 1.3 clients.
- Preserved FROST, Obsidian, five Cute themes, native backup/rollback, ANI lifecycle, four renderers, click effects, tray and WindowChrome.

Validation: 180 core, 85 desktop, 98 interface, 99 cached restart, 28 collection, 51 online security, 104 curation, 103 live online WPF, 10 publisher pipeline and 98 actual old-client checks. All passed. Public package/media/signature verification and actual upgrade use existing guarded scripts. See the Chinese delivery, resource audit and actual WPF captures in docs.

Windows 11 single-display 100% DPI tested. Windows 10, mixed physical DPI, dual displays, long-term load and the full uninstall matrix remain unverified. Screenshots rasterize the running WPF window; stale desktop captures are excluded.

Installer and portable packages retain the built-in library. Additional curated resources are independently distributed by the cursorium-library Releases and downloaded through Explore. Original author attribution and license terms remain in each package and the source audit.
