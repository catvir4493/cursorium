# v1.5.2 性能验证协议

本文件定义测量方法，不宣称尚在执行的试验通过。实际结果由交付报告和原始 CSV/JSON 给出。

## 基线与独立性

- v1.4.0：6886ea6，原始 .NET 8.0.24 自包含程序。
- v1.5.0：c59bd26，原始 .NET 10.0.13 发行 ZIP。
- v1.5.1：8da97e5，原始 .NET 10.0.13 程序。
- v1.5.2：本轮候选，.NET 10.0.13；候选二进制在测量前冻结并记录 SHA256。

正常安装已是 v1.5.1，不能退回并冒称它仍是 v1.5.0。生产安装、配置和原生指针先建立新的私有回退点；开发在独立工作树中进行。

PerformanceHost 以同一源码分别编译到准确的两个运行时，加载冻结的原始 App/Core 程序集，调用原 App.Start 和原 TrailEngine。不修改被测引擎、不调用 Apply；Storage 在创建应用之前指向全新隔离数据目录。测量时独占 CURSORIUM 实例，结束恢复生产托盘。它测量生产应用组件，但不是原版 Main 入口；原可执行文件的启动探针另行运行。

## 交替矩阵

模式：Disabled、Idle、Comet、Minimal、Neon、Stardust、120 Target、Power 30、首次开窗后关闭驻留、高频移动/点击；另有观察器自身和 8ms 计时循环两个校准模式。

每模式/版本 3 轮，轮次和模式间轮换版本顺序；每轮独立进程，5 秒预热、20 秒稳定阶段。保留预热数据，统计阶段排除预热。不强制 GC，不改变分层编译/PGO 默认值，不降低粒子、长度、透明度或视觉质量以获得低 CPU。

所有自动化活动模式使用同一个独立 .NET 10 输入驱动二进制。每轮分别记录其 CPU、实际事件数量和点击到达数量；驱动 CPU 不并入目标进程 CPU。程序性位移不称作物理 HID 输入。真实手动输入单独记录，按 Escape 中止的轮次不得作为完成对照。

观察器以约 1Hz 采集目标进程单核/整机 CPU、机器总体忙碌比例、Working Set、Private Bytes、GDI/USER、线程、GC 和分配速率、采样/渲染计数。记录每轮 CPU 均值，并计算跨轮中位数及实际秒级观测的 P95。Windows CPU 计数有量化误差；P95 不是三轮均值的可靠置信区间。观察器在目标进程内的开销通过空宿主校准单列，不盲目从每项结果中相减。

空闲、禁用和校准段若指针位置观测变化，标记干扰并从对应汇总中排除；不据此认定是用户手动输入。早期宿主没有单独保存 GetPhysicalCursorPos 的成功标志，无法回溯区分位置变化的来源；更新工具另存 pointerAvailable，失败的观测不能用于验收。保留原始记录，必要时另做补测。活动段核对实际到达目标窗口的移动/点击，不能把尝试发送的事件数当成送达。当前机器是交互式工作站，不冒称专用实验室或所有后台负载均已消除。

PaintCount/PaintTicks 仅较新版本存在；v1.4 缺少的数值必须为 null，不能填零冒称没有绘制。计数得到的是 CPU 绘制耗时的采样窗口均值，以及该均值分布的 P95；不是逐帧 P95、GPU 时间或屏幕实际呈现 FPS。渲染目标、Invalidate/绘制计数和实际刷新率必须区分。

## 启动与 profiling

初轮每个原版可执行文件运行 15 次交替 state-probe，原始记录保留；后续工具增加明确的预热轮次并另存复测。记录 Process.Start 调用耗时和整个状态探针进程寿命。后者包括状态读取、报告写入和进程退出，不能称作首次绘制或首次交互时间。公共宿主还单独测量原 ThemeService/StudioService 构造完成；其显式 managed Main 时钟不包含 CLR/宿主预初始化成本。

托盘注册、首次开窗返回、ContentRendered 和随后 Input 优先级调度分别观测；Shell 图标矩形查询失败时保留缺失，不能将 NotifyIcon.Visible 当作屏幕像素已经出现。宿主的托盘/窗口里程碑与原 Main 进程计时是不同实验。

Profiling 轮次与计时矩阵分开。使用 dotnet-trace 的 dotnet-common 和 dotnet-sampled-thread-time；后者采样的是线程栈的墙钟时间，等待栈比例不能当作 CPU 占比。另用 OS 进程/线程 CPU 计数。内核 WPR CPU trace 在当前非提升权限环境实际返回 0xc5585011；在没有更强证据时，不将未解析的 native CPU 归因于某个 .NET/WPF 函数。

依据：[微软 dotnet-trace 文档](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/dotnet-trace)。原始 trace 仅留本地，不上传本机路径或用户环境。

## 验收边界

不因新增断言数、低于某个临时阈值或单轮改善而批准 Stable。确认的差异须由多轮、相同实际负载和独立控制复核；未能解决的真实回归明确列为阻断。20 分钟或一小时测量不代替 24/72 小时压力测试；单屏、100% DPI 不代替真实双屏或混合 DPI。

完整验收仍要求旧回归、隔离安装和用户数据/原生值保护检查。本轮用户已暂停自动输入；未复跑的 WPF、原生事务与长压检查保持 Pending，不用历史结果代替本轮通过。新增发行字节核验，将可执行文件版本/提交、portable 清单、源码 ZIP 与当前提交的规范 Git 对象、四个资产的 SHA256 对齐；公开下载后再次核对。预发布仍使用 -Prerelease，保留 v1.4 Latest Stable 与所有旧 tag。
